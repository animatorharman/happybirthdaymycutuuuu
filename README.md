# Birthday Bloom

Create a beautiful, premium, interactive birthday website for my best friend. The website should feel like a personalized digital birthday surprise — cute, emotional, elegant, playful, and memorable, but NOT romantic. Do not use any “I love you” or romantic relationship language.

Overall aesthetic

Main color palette: soft baby pink, blush pink, pastel pink, white, with subtle accents of lavender and champagne/gold.

Add beautiful ribbons and bows in different shades of pink, similar to a carefully decorated birthday gift.

Use soft gradients, subtle sparkles, floating hearts/stars, gentle glowing effects, and elegant animations.

Make everything feel polished and premium rather than childish.

Use a combination of a beautiful elegant serif font for headings and a clean modern font for body text.

The website should have smooth scrolling and tasteful animations throughout.

Fully responsive and optimized for both desktop and mobile.

Avoid excessive animations that make the website slow or distracting.

HERO SECTION

Create a dramatic birthday opening screen.

Large heading:
“Happy Birthday, [HER NAME]! 🎀”

Subheading:
“To my favourite person and one of the most special people in my life…”

Add a beautiful animated pink gift box in the center with ribbons.

Include a button:
“Open Your Surprise 🎁”

When the button is clicked:

Animate the gift box opening.

Release subtle sparkles/confetti.

Smoothly reveal the rest of the website.

Play a soft celebratory animation, but DO NOT automatically play audio.

Add a small line underneath:
“Your birthday surprise is waiting for you…”

BIRTHDAY MESSAGE SECTION

Create a beautiful section titled:

“Today is all about you ♡”

Write a heartfelt best-friend birthday message that feels genuine and personal. The tone should be warm, emotional, slightly playful, and appreciative.

The message should talk about:

How grateful I am to have her as my best friend.

The memories, laughter, random conversations, and unforgettable moments we have shared.

How she makes ordinary days more fun.

How much I appreciate her presence in my life.

Wishing her happiness, success, peace, and beautiful experiences in the coming year.

Remind her that she deserves an amazing birthday.

Do NOT make it romantic.

End with:
“Happy Birthday once again, [HER NAME]. Keep being the amazing person you are. 🎀”

PHOTO MEMORY GALLERY

Create a beautiful interactive photo gallery titled:

“Our little collection of memories 📸”

I will upload my own photos later, so create clearly marked image placeholders.

Use around 8–12 photo slots.

Make the gallery visually interesting:

Polaroid-style cards

Slight rotations on some cards

Pink tape/ribbon decorations

Hover animations

Soft shadows

Clicking a photo should open it in a beautiful lightbox/fullscreen viewer.

Under the gallery, add:
“Some memories deserve to stay forever.”

“REASONS YOU’RE AWESOME” SECTION

Create a playful section titled:

“Why you’re one of my favourite humans 🎀”

Create animated cards with reasons such as:

You make everything more fun.

You somehow make me laugh at the most random things.

You’re always yourself.

You create memories without even trying.

You’re genuinely special.

You make ordinary moments unforgettable.

You’re impossible to replace.

Make the cards appear one by one as the user scrolls.

MEMORY TIMELINE

Create a horizontal/vertical interactive timeline titled:

“From then to now ✨”

Leave editable placeholders where I can add important memories and dates.

Example:
“Chapter 01 — The beginning”
“Chapter 02 — The first unforgettable memory”
“Chapter 03 — The funniest moments”
“Chapter 04 — All the chaos 😂”
“Chapter 05 — Today 🎂”

Make each timeline item expandable so I can later edit the text and add photos.

BIRTHDAY COUNTDOWN / CELEBRATION

Since the website is being made specifically for her birthday, create a birthday celebration section with:

“THE DAY IS HERE! 🎂”

Show animated numbers/cards for:
“16” / “17” / “[AGE]”

Make the age easy to change in the code.

Add animated balloons, ribbons, stars and confetti around this section.

SPECIAL SURPRISE SECTION

Create a mysterious section titled:

“Wait… there’s one more thing 👀”

Initially show a closed pink envelope/card.

Button:
“Open it 💌”

When clicked, animate the envelope opening and reveal a final heartfelt message.

The message should say something along the lines of:

“Another year, another collection of memories waiting to happen. I hope this year brings you countless reasons to smile, amazing opportunities, unforgettable adventures, and everything you’ve been wishing for. No matter how chaotic life gets, I’m genuinely grateful that I get to call you my best friend. Here’s to another year of random conversations, stupid jokes, unforgettable memories and absolutely unnecessary chaos. 😂🎀

Happy Birthday, [HER NAME]. You deserve the happiest day ever.”

Keep it strictly best-friend themed, not romantic.

FINAL BIRTHDAY SCREEN

At the very bottom, create a beautiful full-screen celebration.

Large text:
“Happy Birthday, [HER NAME] 🎂🎀”

Below it:
“Here’s to another year of being absolutely amazing.”

Add:
“Made with way too much effort, questionable amounts of sleep, and lots of love for my best friend. 😂🎀”

Use a large animated pink bow/ribbon, floating particles and subtle confetti.

Add a button:
“Celebrate Again 🎉”

Clicking it should trigger a beautiful confetti animation and scroll back to the top.

INTERACTIONS & ANIMATIONS

Include:

Smooth page transitions

Scroll reveal animations

Floating hearts/sparkles

Subtle parallax effects

Hover animations

Interactive photo cards

Gift-opening animation

Envelope-opening animation

Confetti celebration

Elegant cursor effects on desktop

Mobile-friendly touch interactions

Keep animations smooth and tasteful.

IMPORTANT DESIGN RULES

Do NOT make the website look like a generic birthday template.

Make it feel custom-designed and personal.

Avoid excessive emojis; use them strategically.

No romantic imagery such as kissing, couples, wedding imagery, etc.

No “girlfriend,” “wife,” “soulmate,” or romantic language.

Prioritize visual beauty and emotional impact.

Make the pink ribbons/bows a recurring visual motif throughout the website.

Use lots of whitespace and elegant typography.

Make sure text remains readable against the backgrounds.

Optimize images and animations for performance.

Make every section easy for me to edit later.

Use placeholder text such as [HER NAME], [AGE], [MEMORY], [DATE], etc. wherever personalization is required.

TECHNICAL REQUIREMENTS

Build the website as a polished production-quality responsive web app.

Use reusable components for:

Navbar

Birthday hero

Photo gallery

Memory cards

Timeline

Surprise envelope

Confetti animation

Footer

Keep the code clean and well organized.

Most importantly, make the first screen visually stunning enough that when she opens the website, it immediately feels like a special birthday surprise.

Reduce anything that looks generic or childish, improve spacing/typography, and make the animations smoother.” That usually helps turn a decent first generation into something much more polished.
