# Premium Birthday Surprise Website

## Goal

Create a polished, responsive, romantic birthday experience for a best friend, using editable placeholders such as `[HER NAME]`, `[AGE]`, `[DATE]`, and `[MEMORY]`.

## Experience

- Build a dramatic opening screen centered on an animated pink gift box and a single “Open Your Surprise” action.
- Reveal the rest of the page only after the gift opens, with tasteful confetti and smooth scrolling.
- Add the heartfelt birthday note, a 10-slot Polaroid memory gallery with fullscreen viewing, animated reasons cards, an expandable memory timeline, age celebration, opening envelope, and full-screen finale.
- Make “Celebrate Again” launch confetti and return to the opening screen.
- Keep all writing strictly best-friend themed, warm, playful, and free of romantic relationship language.

## Visual Direction

- Use baby pink, blush, white, lavender, and restrained champagne accents.
- Repeat custom ribbon and bow details throughout, supported by subtle sparkles and light floating particles.
- Pair an elegant serif heading face with a clean modern body face.
- Favor generous spacing, editorial typography, soft shadows, and restrained motion over generic birthday-template styling.
- Support desktop pointer effects, keyboard use, touch interactions, reduced-motion preferences, and mobile layouts.

## Technical Details

- Organize the experience into reusable React sections and interaction components.
- Keep personalization values and gallery/timeline data in clearly named arrays/constants near the top of the page.
- Use lightweight CSS/React animations and canvas-free DOM confetti to keep performance smooth.
- Add unique page metadata and verify the finished result in desktop and mobile viewports.
